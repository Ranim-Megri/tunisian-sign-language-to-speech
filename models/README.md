# Models Directory

Runtime modules and trained artefacts for the sign classifier and the Derja TTS engine. `main_pipeline.py` (PC) adds `models/` to `sys.path` and resolves model paths relative to the project root.

---

├── hand_landmarker.task            # MediaPipe task (fallback copy)
│
├── sign_classifier/

│   ├── exploration/                # Dataset inspection + landmark extraction notebooks
│   │   ├── explore_dataset.ipynb
│   │   └── extract_landmarks.ipynb

│   ├── results/
│   │   ├── landmarks.csv           # Extraction output (copy)

## MediaPipe hand-landmark task

`hand_landmarker.task` is a pre-trained Google MediaPipe binary (21 hand keypoints). It is downloaded, not generated by this project:

```
https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
```

### Resolution order

| Caller | Behaviour |
|---|---|
| [`main_pipeline.py`](../main_pipeline.py) | Uses `assets/sign_data/hand_landmarker.task`; falls back to `models/sign_classifier/models/hand_landmarker.task`, `models/hand_landmarker.task`, then `assets/audio/hand_landmarker.task`. Raises `FileNotFoundError` if none exist. |
| [`sign_classifier/inference/test_live.py`](sign_classifier/inference/test_live.py) | Uses `assets/sign_data/hand_landmarker.task`, then `models/hand_landmarker.task`; **auto-downloads** if neither exists. |
| [`tests/run_sign_classifier.py`](../tests/run_sign_classifier.py) | Uses `assets/sign_data/hand_landmarker.task`, then `models/hand_landmarker.task`. |

`main_pipeline.py` configures:

```python
vision.HandLandmarkerOptions(
    base_options=python.BaseOptions(model_asset_path=str(TASK_PATH)),
    running_mode=vision.RunningMode.IMAGE,
    num_hands=2,
    min_hand_detection_confidence=0.35,
    min_hand_presence_confidence=0.35,
    min_tracking_confidence=0.35,
)
```

Detected landmarks are passed to `landmarks_to_features()` → 129 floats → `model.predict_proba()`.

## Classifier artefacts

| File | Description |
|---|---|
| `sign_classifier/models/model.joblib` | `Pipeline([('scale', StandardScaler()), ('classifier', SVC(C=10, class_weight='balanced', probability=True))])`; 24 classes; best careful-split macro-F1 (0.8763). Used by default by `main_pipeline.py`, `test_live.py` and the test runners. |
| `sign_classifier/models/landmarks.csv` | Training matrix: `sign`, `path`, `f0`…`f128`; 1302 rows over 24 signs. |
| `sign_classifier/models/comparison_metrics.csv` | Accuracy / balanced accuracy / macro F1 for 6 classifiers on the careful and random splits. |
| `sign_classifier/results/landmarks.csv` | Working copy produced by the extraction notebook. |
| `sign_classifier/results/failed_pictures.csv` | Pictures where landmark detection failed. |

## Adding or updating a model

1. Refresh `models/sign_classifier/models/landmarks.csv` (see the extraction notebook in `sign_classifier/exploration/`).
2. Run from the project root:
   ```bash
   python models/sign_classifier/training/compare_models.py
   ```
   It trains six models, prints the comparison, retrains the winner on all rows with flip augmentation, and **overwrites** `model.joblib` and `comparison_metrics.csv`.
3. Select a different filename at runtime (only `model.joblib` ships today):
   ```bash
   python main_pipeline.py --model model.joblib
   ```

See [`sign_classifier/training/README.md`](sign_classifier/training/README.md) for feature details and scores, and [`tts/README.md`](tts/README.md) for the speech side.
